# Aperta — מערכת המותג

הלוגו הגיע כתמונה אחת (`aperta-logo.png`). כל מה שהאתר מגיש נגזר ממנה דרך
`build-brand-assets.py`, כדי שהחלפת הלוגו תהיה החלפת קובץ אחד והרצה — ולא
מרדף אחרי עשרה נכסים ביד.

```
python3 docs/brand/build-brand-assets.py
```

## השם

| היכן | מה |
| --- | --- |
| `he.site.brand` | `Aperta` — השם היומיומי, בהדר, בכותרות, בחתימות מייל |
| `he.site.brandFull` | `APERTA DESIGNS` — הנעילה המלאה, לשימוש שהמותג נאמר במלואו |
| `he.site.brandSub` | `DESIGNS` — השורה שמתחת למילולוגו. **לא חייבת להופיע**; היא מופיעה בפוטר ובתמונת השיתוף, ולא בהדר |
| `he.site.brandHe` | `אפרטה` |

`aperta` היא "פתוחה" בלטינית — וזה גם המוצר (צמיד פתוח, טבעת פתוחה) וגם
הסימן (טבעת עם פתח).

## הסימן

הטבעת הפתוחה. **גאומטריה, לא אותיות** — ולכן הוא עובד בכל גודל ובכל הקשר,
כולל פאביקון, שבו הקשר הרינדור אינו טוען ווב-פונטים כלל.

זהו הנכס שמופיע לבדו בכל מקום שאין בו מקום לנעילה המלאה: פאביקון, אייקון
אפליקציה, אווטאר. `BrandMark` ב-`src/components/site/BrandMark.tsx` הוא מקור
האמת שלו; `src/app/icon.svg` נושא עותק של אותה גאומטריה (ומצוין שם).

מדידות מ-`aperta-logo.png` (פיקסלים במקור):

| מה | ערך |
| --- | --- |
| מרכז | (728, 316) |
| רדיוס חיצוני | 143 — מעגל מושלם |
| פנים | אליפסה 123.5 × 128.5 — הטבעת עבה יותר באגפים (19–20px) מאשר למעלה ולמטה (15px), כמו O של גרסה סריפית |
| פתח | 253.5°–289.5° (מעלות שעון, 0° = מזרח) |
| קשת ההדגשה | 289.5°–325.5°, מיד אחרי הפתח |

ב-`viewBox 0 0 64 64` זה מתורגם למרכז (32,32), רדיוס 30, פנים 25.91 × 26.96.

## המילולוגו

"Aperta" בגרסה סריפית בעלת ניגוד גבוה מאוד. הגופן אינו אחד מגופני האתר, והוא
לא נטען כווב-פונט: האותיות מנותבות לנתיב SVG אחד (`Wordmark.tsx`), 6KB, מתוך
`aperta-logo.png`. הניתוב פולט אלפי קוביות שהן בפועל קווים ישרים, ולכן הוא עובר
פישוט (`_simplify`, ε=0.02) שמוריד אותו פי 2.5 בלי הבדל שנראה לעין.

מוט ה-A בכחול — קו ישר, ולכן מלבן ולא נתיב מותווה.

`viewBox 0 0 102.7 27.6` · גובה אות רישית 20 · קו בסיס ב-y=20.

שורת ה-`DESIGNS` היא **טקסט חי** ולא ווקטור: רשומית מרווחת בגופן סנס, שנראית
נכון בכל גופן — בניגוד למילולוגו, שהאותיות שלו הן הצורה עצמה.

`lapis` הוא הכחול של הלוגו. הוא החליף את `cobalt` (`#315bff`) — כחול חשמלי
שהיה טוב לכשעצמו אבל התנגש עם הכחול השקט של הסימן. הוא גם עבר בניגוד: 5.53:1
במקום 4.58:1.

## מה עדיין נושא את המותג הישן

- **שמות התשתית** — ה-Worker (`forme-studio`), ה-Worker של המסגור
  (`forme-frame`), הקונטיינרים (`forme-vectorizer`, `forme-geometry`) ומרחב
  ה-UUID של ניסיונות היצירה. שינוי שם Worker אינו שינוי קוד אלא **הגירת פריסה**:
  הוא יוצר Worker חדש ומשאיר את הדומיין המותאם, ה-bindings וה-secrets על הישן.
  זה צעד נפרד, בתיאום עם לוח הבקרה של Cloudflare.
## התצלומים

הקובייה הכחולה בתצלומי המוצר היא אביזר סטיילינג שכל תפקידו לשאת את צבע
המותג — ולכן היא נשאה את הקובלט הישן. במקום להשאיר התנגשות בכל עמוד היא עברה
תיקון גוון חד-פעמי ב-`bracelet-hero`, `ring-hero` ו-`hand-wrist`:

| מה | ערך |
| --- | --- |
| מסכה | פיקסלים כחולים־דומיננטיים (`b-r > 0.12`, רוויה > 0.3) שנופלים ב**רכיב מחובר של 5000 פיקסלים ומעלה** |
| טרנספורמציה | גוון −11.7° · רוויה ×0.722 · בהירות ללא שינוי |

סף הרכיב המחובר הוא מה שמפריד בין האביזר למוצר: הקובייה היא כתם של ~30 אלף
פיקסלים, והאבן הכחולה שבטבעת — כמה מאות. **המוצר עצמו לא נגע.** `hand-ring`,
שאין בו קובייה, נותר בית-בבית כפי שהיה.

התיקון הוא חד-פעמי ולא שלב build: הרצה שנייה עליו הייתה מזיזה את הגוון שוב.
לביטול — `git checkout` לגרסה הקודמת של הקבצים.
