# E. לסגור את `/debug` — חשיפת מידע לקוחות

**זה הפריט הדחוף ביותר במסמך.** נמדד מול הייצור (26.7), בלי שום אימות:

```
GET /api/debug/log                       → 200, 80 הרצות
GET /api/debug/log/<id>                  → 200, 288KB פירוט מלא
GET /api/debug/log/<id>/image/render     → 200, PNG של 1.7MB
```

מתוך 80 ההרצות, **15 מכילות טקסט חופשי שלקוחות כתבו** — למשל
`"תיאור הלקוחה: עלים המחוברים אחד לשני, רק קווי המתאר שלהם..."`. נחשפים גם
הפרומפט המלא, ההדמיות שנוצרו, זמני ריצה, שם המודל ומדדים פנימיים.

`requireAdmin` כבר קיים ב-`src/lib/admin.ts` ומשמש ב-`inquiries` — אבל **בכל
`src/app/api/` הוא מופיע רק שם**. ארבעת מסלולי ה-debug ועמוד `/debug` לא בודקים
כלום.

- [ ] **E1. `requireAdmin(req)` על ארבעת המסלולים:**
      `api/debug/log/route.ts` · `api/debug/log/[id]/route.ts` ·

- [ ] **E2. שער על `src/app/debug/page.tsx`** — אותו מנגנון של `/admin`
